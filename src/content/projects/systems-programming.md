## Overview

These are course projects, so the code isn't public. I'm happy to walk through any of them in an interview.

- **smallsh**: a Unix shell in C with `fork` and `exec`, input and output redirection, signal handling, and background jobs.
- **Multithreaded pipeline**: a line-processing program in C using pthreads.
- **One-time pad encryption**: a client and server system in C that encrypts and decrypts messages.
- **BLAS vector functions**: Level 1 BLAS routines in x86-64 assembly, using SIMD instructions and the x87 floating point unit.
